# Development Loop

Use this workflow for engineering changes.

1. Plan: define files, commands, and done criteria.
2. Implement minimal diff.
3. Run relevant checks.
4. Review diff separately.
5. Commit with clear message.
6. Prepare PR summary including risks, checks, and follow-ups.

## Guardrails
- Follow root `AGENTS.md` for scope and approval gates.
- Persist decisions in docs/tests/schema, not chat-only notes.
